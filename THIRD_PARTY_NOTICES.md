# Source attribution

The BM25 class and its supporting definitions are extracted from the original saved-run experiment harness. Shared data/type modules are copied from [GEMS-RAG/rag](https://github.com/GEMS-RAG/rag/tree/8e981f2e3ae98a69516206cc19fca010a3f33d4e). Their source revisions, definition spans, and hashes are recorded in [PROVENANCE.json](PROVENANCE.json). The standalone CLI adapts the shared export schema to the original chunk representation.

No additional software license is inferred for study-authored files or the GEMS-RAG source snapshot, which did not supply a project license. Citation metadata does not change the retained licenses.

The shared corpus, MUTCD manual, benchmark, and prebuilt indexes remain in [GEMS-RAG/rag](https://github.com/GEMS-RAG/rag); they are separate from the upstream software licenses.
